## Adotar / evitar / diferenciar
- **Adotar:** captura rápida em linguagem natural (ex.: "estudar redes quarta 14h") — é exatamente o espírito do chat (req. 07); Karma como inspiração para motivação, sem exagero.
- **Evitar:** recursos centrais bloqueados no plano grátis (calendário).
- **Diferenciar:** Todoist organiza *tarefas*; nós organizamos *tempo de estudo* (pomodoros, extra, capacidade, desempenho).
- **Para o Agente 2 verificar (design):** entrada rápida de tarefa, visão Hoje/Próximos 7 dias, uso de cor/prioridade.
